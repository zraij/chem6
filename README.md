# كيمياء السادس العلمي

شرح مصوّر وتفاعلي لفصول كتاب الكيمياء للصف السادس العلمي الثمانية، مع تحدّي الفرق والمختبر التفاعلي.

- **الموقع:** https://zraij.github.io/chem6/ (يحتاج تسجيل دخول)
- **إدارة الحسابات:** https://zraij.github.io/chem6/admin.html (لصاحب الموقع فقط)

محتوى الصفحة مشفّر، ولا يُفتح إلا بحساب صحيح. الحسابات محفوظة في `users.json` بشكل مشفّر، وتُدار من صفحة الإدارة.

- **رابط التثبيت (يُرسل للأساتذة):** https://zraij.github.io/chem6/install.html — يثبّت البرنامج كتطبيق على الموبايل والشاشات التفاعلية
- **حساب الشاشة التفاعلية:** من صفحة الإدارة ← «إضافة شاشة تفاعلية»، حساب لكل شاشة حتى ما تنقفل حسابات الأساتذة عليها
- **تنبيه للمطوّر:** بعد أي إعادة بناء لـ `index.html` تأكد أن سطر `manifest.webmanifest` وكود `__PWA` بعده موجودان، وإلا يختفي التثبيت كتطبيق
